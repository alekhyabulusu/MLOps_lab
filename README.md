# MLOps_lab1
This repository contains the required lab1 for the MLOps course as part of the coursework.
It demonstrates a basic MLOps workflow using Python, automated testing, Git, and GitHub Actions.

## Project Structure

- `src/` - Contains the calculator source code
- `test/` - Contains Pytest and Unittest test cases
- `data/` - Directory for project data
- `.github/workflows/` - Contains GitHub Actions workflows

## Calculator Functions

The calculator implements arithmetic operations including:

- Addition
- Subtraction
- Multiplication
- Combined arithmetic operations
- Division

## Testing

We use two testing frameworks:

- Pytest
- Python Unittest

## GitHub Actions

Two GitHub Actions workflows are configured to automatically run
Pytest and Unittest whenever changes are pushed to the
main branch.
